# firn — Logo, final

**Mark:** a glowing ridge (the peak) with a small neural network inside: six neurons in three layers, 1 · 2 · 3, each layer wired to the next. The outer links run parallel to the ridge.
**Thinking state:** the same network, with one lit path running from the top neuron down while the rest dims. The animated version moves that path through the net.
**Wordmark:** FIRN in Inter Light, tracked 0.42 em, converted to outlines (no font needed).
**Colour:** #000 and #fafafa only. Greys are white at lower opacity. No accent colour.

## Rules

- Use the glow version only on black. On anything else, use the flat version.
- Below 48 px, always use the small version.
- In running text the name is lowercase: firn. In the wordmark and in UI chrome: FIRN.
- Android adaptive icons crop to a circle or squircle: the 1024 master keeps the mark inside the safe zone. Check the small icon on a real launcher.
- Don't recolour, rotate, outline or add effects to the mark beyond the glow that comes with it.
